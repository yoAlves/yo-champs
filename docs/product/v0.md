## 2. Vision and scope

### 2.1 Final goal

A personal desktop companion that centralizes quick questions, pluggable
specialists (OCR, transcription, translation, calendar, documents), tools/MCP,
memory/RAG, local or remote models, nostalgic personality with asset packs, and
a plugin/multi-OS architecture.

### 2.2 V0 goal

A small, reliable macOS app that:

- lives in the menu bar (no Dock icon);
- is invoked by a global hotkey;
- shows the character on screen, closable without killing the process;
- answers in 1–2 sentences with streaming;
- keeps multi-turn conversations;
- lets the user configure provider/model/key;
- loads asset packs;
- ships tests, CI, licenses and security from day one.

### 2.3 Non-goals (V0)

OCR, transcription, calendar, web search, attachments, MCP, RAG/long-term
memory, local models, multi-OS, auto-update, App Store, telemetry,
side-effectful tools.

### 2.4 Anti-goals

Electron/Tauri/Rust on the critical path; a generic chat app; an agent
framework; copying Microsoft assets; cloud dependency; over-engineering;
leaking secrets; scope creep that breaks V0.

### 2.5 Principles

- Local-first.
- Pure, portable Core; thin macOS shell.
- LLM/framework agnostic.
- Data over code: providers, agents, tools and packs are configuration.
- Functional core, imperative shell.
- Nostalgia with an original inspired character.
- Security and privacy are requirements.

## 6. Architecture summary

```
YoChampsMac (menu bar, hotkey, panels, bubble, settings, mascot)
    │ async/await in-process
YoChampsCore (engine, context, provider, tools, storage, commands)
    │
OpenAI-compatible API (OpenRouter / OpenCode Go / Ollama / LM Studio)
```

Dependency rule: `YoChampsMac` → `YoChampsCore` → Foundation. Core imports no
AppKit/SwiftUI and knows no provider, model or vendor name.

Details: `docs/architecture/overview.md`, `docs/architecture/contracts.md`,
`docs/architecture/data-and-versioning.md`, `docs/architecture/mascot-pack.md`.

## 8. Providers and configuration

Core only knows `ProviderProfile`:

| Field | Purpose |
|---|---|
| `id`, `label` | identification |
| `kind` | `openai-compatible` in V0 |
| `baseURL` | endpoint |
| `model` | model id (data) |
| `headers` | extra headers with placeholders |
| `secretRef` | Keychain reference |
| `capabilities` | streaming, reasoningEffort, tools, maxContext |
| `isDefault` | user’s default profile |

- No provider/model names in Core. The code does not know “OpenRouter”,
  “OpenCode” or “Go Plus”.
- No real provider is a default. Without one, onboarding runs; `MockProvider`
  serves demo and tests.
- Key in Keychain; `config.json`/Settings hold only `secretRef`.
- “Test connection” calls `/models` or a minimal completion.
- `headers` accepts `{{conversationId}}`, `{{appVersion}}`, `{{userAgent}}`.
- Example profiles in docs: OpenRouter, Ollama, LM Studio, OpenCode Go.
- Slash commands in V0.1: `/models`, `/model`, `/provider`, `/effort`, `/new`,
  `/clear`, `/history`, `/mascot`, `/settings`, `/copy`, `/retry`, `/stop`,
  `/help`, `/quit`, `/reload`. `/quit` terminates; `Esc` hides.

### OpenCode Go Plus

An OpenAI-compatible provider, not the OpenCode runtime.

- Base URL: `https://opencode.ai/inference/go/openai/v1`
- Models: `https://opencode.ai/inference/go/v1/models`
- Key: OpenCode console, stored in Keychain
- Recommended header: `x-opencode-session: {{conversationId}}`
- Model ids are data (e.g. `deepseek-v4.1-flash`, `glm-5.3-flash`)
- Intended use is a coding agent; use as a personal profile in V0, never as a
  public default.
- The OpenCode runtime (sessions/agents) is a future `AgentBackend`, separate.

Personal profile example (not shipped):

```json
{
  "id": "personal-go",
  "label": "Personal Go",
  "kind": "openai-compatible",
  "baseURL": "https://opencode.ai/inference/go/openai/v1",
  "model": "deepseek-v4.1-flash",
  "headers": { "x-opencode-session": "{{conversationId}}" },
  "secretRef": "keychain:provider/personal-go",
  "capabilities": ["streaming"]
}
```

`isDefault` is optional in `config.json` (defaults to `false`). The loader maps
the wire `kind` to a vendor-neutral Core `ProviderKind` and resolves `secretRef`
(`keychain:<service>/<ref>`) through the Keychain; the key itself is never stored
in config.

## 9. Mascot, asset packs and license

Format: `manifest.json` + `spritesheet.png` + `preview.png`. Fields: `id`,
`name`, `version`, `author`, `license`, `frameSize`, `scale`, `anchor`,
`animations` (`idle`, `thinking`, `talking`, `happy`, `confused`, `error`;
each with `frames`, `fps`, `loop`).

- **Default:** original “cousin of Clippy” — paperclip, own silhouette/eyes/
  colours/animations, name **Champ**, original lines. Strong nostalgic
  inspiration, no copy of Microsoft’s expression.
- **Local pack:** `~/Library/Application Support/YoChamps/Mascots/<id>/`, out
  of git. A real Clippy pack may live there for personal use.
- **Validator:** checks manifest, dimensions, frames, required states, license
  and size.
- **License:** code MIT; original assets CC BY 4.0; `ASSETS.md` with
  provenance; README disclaimer.
- **Legal:** fair use is not a license; consult IP counsel for App
  Store/commercial use. The public repo contains no Microsoft assets.

**MCP:** executable dependency. Pin version/command, review, least privilege,
no inline secret (`{env:VAR}` or OAuth), opt-in, off the build/test critical
path. Do not use MCP to validate UI; use XCUITest, snapshots,
`YoChampsMascotValidator` and evals.

## 12. Security, privacy, quality

- **Secrets:** Keychain; gitleaks in pre-commit/CI; GitHub secret scanning +
  push protection; logs with `privacy: .private`; no key in fixtures/screenshots.
- **Prompt injection:** system/developer/user hierarchy; attachment/web content
  is always data; no side-effectful tools in V0; confirmation/allowlist when
  they arrive; eval with “ignore the instructions”.
- **Privacy:** no telemetry; local history; provider calls only on explicit
  action; “clear history”.
- **Tests:** unit + contract + integration with `MockProvider` + XCUITest;
  small evals (5–10) on a weak model, manual/nightly.
- **Git:** public repo; short-lived branch + PR into protected `main` (PR +
  required checks); Conventional Commits; tags `v0.x`.
- **Release:** local in V0; signing/notarization and DMG only when public;
  sandbox/App Store decided later.
- **`.gitignore`:** macOS, Xcode, SwiftPM, `.env*` (except `.env.example`),
  `*.p8`, `*.p12`, `*.mobileprovision`, `*.gguf`, `*.mlx`, `scratch/`, `notes/`,
  `.specs/`, `*.scratch.md`, `*.local.md`, `*.session.md`, auth/OAuth,
  `DerivedData`, coverage.

Each milestone contract lives in `docs/delivery/milestones/MN.md`.

**Completion report:** what changed, criteria met, commands + output, evidence,
gaps and risks. The reviewer checks against the contract; the agent does not
self-certify. `docs/delivery/status.md` records milestone, state, gate,
evidence and date.

**V0 definition of done:** menu bar + hotkey + question + 1–2 sentence streaming
answer + multi-turn + show/hide + configurable provider + restart with history +
`make verify` green + no secrets/Microsoft assets in git.

**Target metrics (report, do not block early):** cold start < 2s; idle memory
< 100MB; app < 20MB without models; first token < 3s on a fast model; zero
crashes in a 10-minute soak.
