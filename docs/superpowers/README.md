# Superpowers design records (historical)

These `plans/` and `specs/` are dated working artifacts from the design sessions
that produced M3 and the post-M3 Ask panel work. They record how a change was
reasoned about at the time; they are **not** the current product contract.

- The binding contract is `docs/product/v0.md`, with decisions in
  `docs/decisions/` and current state in `docs/delivery/status.md`.
- The M3 floating-panel, drag and persisted-position design was superseded by
  [ADR 0012](../decisions/0012-embedded-champ-ask.md); the old specs still
  describe it on purpose.
- New work does not need a file here. Promote durable decisions to an ADR and
  the product/delivery docs.
- The artifacts keep their original language (some are in Portuguese) and may
  reference code that was later removed, such as `MascotImageView.swift`.
