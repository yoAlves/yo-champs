## Goal

Bring Champ to life: a floating, transparent character window driven by
semantic states, a global hotkey, show/hide, drag with persisted position, and
the default asset pack rendered beside the answer bubble.

## Non-goals

- No pack marketplace, pack editor or remote downloads.
- No OCR, transcription, calendar, tools or MCP.
- No signed distribution.

## Deliverables

1. Menu bar: Ask, Show/Hide, Settings, Quit, all functional.
2. Global hotkey with recorder UI (`KeyboardShortcuts`), default chosen after
   conflict check.
3. `NSPanel`/`NSWindow` floating, borderless, transparent, always-on-top;
   close hides without terminating.
4. `MascotRenderer` mapping `CompanionState` → animation frames, with timers
   driven by the pack manifest (fps, loop).
5. Drag with persisted position; safe placement across screens.
6. Default Champ pack art (replace the M0 placeholder) and local pack loading.
7. XCUITest for the critical flow (requires full Xcode).

## Acceptance criteria

- [x] Hotkey opens the prompt; Esc closes it.
- [x] Character shows/hides from the menu; process keeps running. (Show/Hide
      now toggles the Ask window.)
- [ ] Drag moves it; position survives restart. **Superseded by ADR 0012; not
      delivered and not claimed.**
- [x] Six semantic states animate from real engine events, not LLM keywords.
- [x] Default and local packs both load; invalid packs are rejected clearly.
- [x] `make mascot-validate` and `make test-ui` green.
- [x] `make verify`, `make deploy` and `make restart` green.

## Verification commands

```sh
make mascot-validate
make test-ui
make verify
make deploy
```

Manual evidence: show/hide, animations during a real answer, restart. (Drag is
historical and superseded by ADR 0012.)

## Risks

- Transparent panels and Spaces/full-screen behaviour; test multi-display.
- Global hotkey conflicts; make it configurable and validate at set time.
- XCUITest needs Xcode; if unavailable the gate stays open (no workaround).
- Timer-driven rendering can burn CPU; idle low-power mode required.

## Exit criteria

Pack validator, XCUITest and verify green, evidence in `status.md`, review with
no open critical/important findings. Met for the shipped shape; drag/persisted
position were superseded by ADR 0012.
