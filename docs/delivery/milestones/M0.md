# M0 — Foundation

**Status:** in progress — local gate, review and clean clone green; remote CI pending.
**Owner:** Yuri Oliveira.
**Plan:** frozen 2026-11-15 plan (materialized in `docs/product/v0.md`).

## Goal

A reproducible repository where a clean clone can bootstrap, verify and install
a menu bar `YoChamps.app` locally, with docs, gates, security and CI from day
zero.

## Non-goals

- No LLM loop, provider, Keychain storage or settings UI (M1–M2).
- No character renderer, hotkey or floating panel (M3).
- No signing, notarization, DMG, auto-update or App Store work.
- No MCP, OCR, transcription, calendar, web search, RAG or telemetry.

## Deliverables

1. SwiftPM workspace: `YoChampsCore`, `YoChampsMac`, `YoChampsMascotValidator`,
   `YoChampsCoreTests`.
2. Menu bar shell with `LSUIElement`, no Dock icon, Quit action.
3. Bundle assembly (`scripts/bundle.sh`), local install (`scripts/deploy.sh`).
4. Makefile with the V0 target surface (implemented or explicitly gated).
5. Tooling: `.swiftformat`, `.swiftlint.yml`, `.gitleaks.toml`, pre-commit hook.
6. CI: `.github/workflows/ci.yml` (Linux Core tests, macOS `make ci`).
7. Docs: `docs/product/`, `docs/delivery/`, `docs/architecture/`,
   `docs/decisions/`, `docs/security/`.
8. Project `AGENTS.md`, `opencode.jsonc`, `.gitignore`, `.env.example`.
9. Licensing: `LICENSE` (MIT), `ASSETS.md` (CC BY 4.0 assets), `SECURITY.md`,
   `README.md`, `CHANGELOG.md`.
10. Default mascot pack contract, validator and placeholder Champ pack.

## Risks

- **No full Xcode on the machine:** `xcodebuild` and XCUITest are unavailable.
  M0 therefore uses SwiftPM + `scripts/bundle.sh` (ADR 0002). `make test-ui`
  stays a documented gate and is blocked until Xcode is installed.
- **Swift Testing with CLT:** the toolchain's `Testing.framework` and libc++
  headers are incomplete; tests use the official `swift-testing` package and
  `scripts/test.sh` supplies the SDK headers. Full Xcode skips the workaround.
- **Unsigned local builds:** Gatekeeper is fine for locally built bundles, but
  distribution needs signing/notarization (post-V0).
- **CI cost:** the macOS job installs Homebrew tools on every run; acceptable
  for V0, cache later.
- **Tool drift:** SwiftLint/SwiftFormat/gitleaks versions are not pinned yet;
  doctor prints them. Pin once CI is stable.
