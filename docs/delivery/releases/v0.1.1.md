# v0.1.1 — Hardening and chat polish

**Released:** 2026-11-19 · **Tag:** `v0.1.1` · [Changelog](../../../CHANGELOG.md)

A hardening release on top of the functional V0: bounded private history,
HTTPS-only remote providers, a tested outbound payload, Markdown answers with
copy on select, a cleaner Ask header, and CI that watches the UI suite without
blocking merges.

## Highlights

- **Local data:** conversation history is capped at 2 MB of encoded JSON (the
  oldest complete turns are dropped, the newest turn is always kept) and is
  written into a `0700` directory with `0600` on `history.json`. ADR 0013 and
  `docs/security/data-and-privacy.md` record what stays local and what leaves.
- **Transport:** provider profiles require HTTPS outside loopback; `http` is
  accepted only for `localhost`, `127.0.0.1` and `::1`. Settings "Test
  connection" validates the URL before reading the key, so a key is never sent
  in cleartext.
- **Payload boundary:** `PrivacyPayloadTests` captures the real provider request
  and fails if the body or headers gain a secret, a path, a Keychain reference
  or a telemetry field.
- **Chat:** `**bold**`, `~~strikethrough~~` and `_italic_` render styled;
  unclosed markers stay literal. Selecting question or answer text copies it
  once on release. The header shows the animated Champ avatar on the left and
  the `+` new-chat button on the right, without the old "CHAMP" capsule.
- **CI:** a separate, non-required `ui` workflow runs `make test-ui` on demand
  and nightly; required PR checks stay `core (linux)` and `app + gates (macos)`.
  `make pr-checks PR=<n>` waits for a PR's checks with a bounded watch instead of
  polling.

## Upgrade

Nothing to migrate: the history schema stays version 1, and existing
`history.json` files load unchanged (large files are trimmed on the next save).
The visible transcript still starts empty on relaunch; stored history remains
model context.

## Known limitations

- History is plaintext for same-user processes; FileVault is the at-rest
  dependency (app-level encryption is future work).
- `http` is loopback-only, so a LAN Ollama/LM Studio endpoint needs HTTPS.
- XCUITest needs full Xcode, a GUI session and `make stop` first.
- Open points, with severity and size, are tracked in
  [`../open-points.md`](../open-points.md).
