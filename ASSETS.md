## Default pack: Champ (`Resources/Mascots/Default/`)

| Field | Value |
|---|---|
| Character | Champ, an original paperclip-inspired companion |
| Author | Yo Champs |
| License | CC BY 4.0 |
| Source | Generated by `scripts/gen-champ-pack.py` (Python 3 + Pillow) |
| Status | Original M3 art (pack version 0.2.0) |

The pack is the original Champ paperclip in six semantic states (`idle`,
`thinking`, `talking`, `happy`, `confused`, `error`) on one horizontal strip.
It is generated from code so the pack contract and validator stay executable;
the art is original and committed, not a Microsoft asset.

Regenerate:

```sh
python3 scripts/gen-champ-pack.py Resources/Mascots/Default
```

## Local packs

Packs installed by a user live in
`~/Library/Application Support/YoChamps/Mascots/<id>/` and are never committed.
That is the sanctioned place for third-party or personal packs, including a
real Clippy pack for private use. Do not add such packs to this repository.

## Third-party references

Design references (timings, window behaviour, provider patterns) are listed in
`docs/product/v0.md`. Reference code is not copied, especially from AGPL
projects. Dependencies are pinned and reviewed before being added.
