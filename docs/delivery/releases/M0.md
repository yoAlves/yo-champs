# M0 — Foundation (`v0.0.0-m0`)

**Released:** 2026-11-16 · **Prerelease** · [Repository](https://github.com/yoAlves/yo-champs)

First public milestone. Yo Champs is a native macOS menu bar companion with an
original paperclip mascot (Champ) and a provider-agnostic LLM core. M0 builds
the foundation; the conversation loop lands in M1.

## What is in this release

- SwiftPM workspace: `YoChampsCore` (pure Foundation), `YoChampsMac` (menu bar
  shell), `YoChampsMascotValidator`, and 18 Swift Testing tests.
- Menu bar app with `LSUIElement` (no Dock icon) and Quit; the final Ask,
  Show/Hide and Settings items are placeholders for M1–M3.
- Mascot pack contract (manifest, horizontal spritesheet, preview), a validator
  with size/geometry limits, and the placeholder Champ pack.
- Makefile-first DX: bootstrap, doctor, build, run, test, format, lint, secrets,
  mascot-validate, verify, ci, deploy (local), restart, stop, open, logs,
  config, mascots, install-hooks, clean; future targets fail loudly by milestone.
- GitHub Actions CI: Linux Core tests plus macOS lint/test/build/pack/secrets.
- Docs: product V0, milestone contracts M0–M4, gates, status, architecture,
  decision log D01–D25 with 8 ADRs, security (threat model, prompt injection,
  MCP policy).
- Licensing and hygiene: MIT code, CC BY 4.0 original assets, `ASSETS.md`,
  `SECURITY.md`, gitleaks, pre-commit hook.

## Gate evidence

## Install locally

```sh
git clone https://github.com/yoAlves/yo-champs.git
cd yo-champs
make bootstrap
make doctor
make verify
make deploy
```

`make deploy` is local-only: unsigned, not notarized, not published. There are
no downloadable binaries in this release; build from source.

## Not included yet

LLM loop and streaming (M1), real providers/Keychain/settings/persistence (M2),
character rendering/hotkey/asset packs (M3), evals/hardening/v0.1.0 (M4).
MCP, OCR, transcription, calendar, RAG, local models, telemetry and auto-update
are out of V0 scope.

## Known limitations

- No full Xcode requirement for M0: builds with Command Line Tools; XCUITest
  (`make test-ui`) needs full Xcode and arrives with M1+.
- Swift Testing comes from the pinned `swift-testing` package (6.2.4) and a
  CLT-only include-path workaround in `scripts/test.sh`.
- macOS 14+ on Apple Silicon; unsigned local install only.
